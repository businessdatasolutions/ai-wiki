description: |-
  We spent two decades learning how to build interfaces for people. Agents are now a large share of the traffic hitting your product, and they need their own. Adithya Krishnan calls it AI/AX — agent interfaces and agent experience — and shows how MotherDuck designed a CLI for it.

  In this video Adithya Krishnan from MotherDuck works through the two agent interfaces MotherDuck ships, the MCP server and the CLI, and how they decided which one should do what. He covers picking the tasks worth evaluating, building an eval harness around them, and grading on token efficiency, step count, and minimal schemas rather than on whether the command merely succeeded, plus what the CLI turns out to be good for beyond running commands, namely letting an agent discover that a capability exists at all. Recorded at the Agents in Prod meetup in Amsterdam, hosted by MotherDuck.
